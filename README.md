# 睡眠改善プロジェクト 〜ショートスリーパー峰小輔の一週間〜

ドット絵＋疑似3D（1点透視）のミニゲーム集。Ruby + [Gosu](https://www.libgosu.org/) 製。

ショートスリーパーの **峰小輔** が、1日のうちに筋トレ・お風呂・サプリメントの
ミニゲームをこなして **睡眠ゲージ** の上昇を食い止める。ゲージが 1000 に達したら
気絶＝ゲームオーバー。1日を乗り切ると夜に **30分だけ** 眠ることが許され、ゲージが
30 だけ減る。これを7日間くり返し、一度も気絶させなければ勝ち。

## 動かす

```bash
gem install gosu
ruby main.rb
```

必要なのは Ruby と gosu だけ。画像・音声のファイルは一切なく、ドット絵はすべて
ソースコード中の文字列から生成している。

## 操作

| キー | 働き |
| --- | --- |
| `SPACE` / `Enter` | 決定・筋トレのバーベル・サプリを飲む・ウトウトからの復帰 |
| `←` `→` | サプリメントのコップを動かす |
| `↑` `↓` | お風呂の湯温を上げ下げ（押しっぱなし） |
| `ESC` | ポーズ（ポーズ中に `T` でタイトル、`Q` で終了） |
| `R` | ゲームオーバー／クリア画面からやり直し |

## ルール

### 睡眠ゲージ

- **0 が通常** ＝ 健康。**1000 で気絶** ＝ ゲームオーバー。
- 時間が経つだけで少しずつ溜まる。日が進むほど溜まる速度が上がる。
- ミニゲームでのミスは、その場でゲージを増やす。
- 1日を乗り切った夜、30分の睡眠で **30 だけ** 減る。7日間しのげばクリア。

### ミニゲーム（1日6本・3種目を2回ずつ）

| 種目 | 内容 | 操作 |
| --- | --- | --- |
| **深夜の筋トレ** | 往復するパワーゲージを緑のゾーンで止める。中央の黄色なら PERFECT。 | `SPACE` |
| **お風呂** | 動く「ちょうどいい温度」の帯に湯温を保つ。「ウトウト…」が出たら即 `SPACE`。 | `↑` `↓` `SPACE` |
| **サプリメント** | 3レーンを迫るサプリを判定ゾーンで飲む。暖色は飲む、寒色（睡眠薬など）は見送る。 | `←` `→` `SPACE` |

### 削減量は「成功の難易度」で変わる

各ミニゲームは制限時間 42 秒でスコアを稼ぐ形に統一してある。

```
達成率 = スコア / 目標スコア   （上限 1.2）
削減量 = その日の上限 × 達成率
```

スコアは **レベル**（種目内の難易度。粘るほど速く・シビアになる）と **コンボ** で
1回あたりの価値が上がるので、難しい成功ほど多くゲージを削れる。1本あたりの削減量の
上限も DAY1 の 100 から DAY7 の 148 まで増えていく。

### バランスの考えかた

- ミスを出さずに丁寧にこなせば、達成率 6 割前後で収支が釣り合う。
- 1日に 200 ぶんのミスを出すと、9 割近い達成率を求められるようになる。
- 何もしなければ 2〜3 日ももたない。

数値は [`lib/suiminkaizen/config.rb`](lib/suiminkaizen/config.rb) に集約してあり、
[`spec/core/balance_spec.rb`](spec/core/balance_spec.rb) がこの関係を見張っている。

## 想定プレイ時間

1日あたりおよそ 5 分、7日クリアでおよそ 35 分。

## 疑似3Dのしくみ

`x:右 / y:下 / z:奥` の世界座標をカメラ原点から `screen = 中心 + 座標 / z × 焦点距離`
で投影しているだけの、ごく単純な1点透視。立体に見せているのは次の3点。

1. **床・天井・壁を透視で敷く** — 奥行き方向のグリッドが消失点へ収束する。
2. **頂点カラーでフォグをかける** — 奥ほど背景色へ沈み、空気遠近になる。
3. **スプライトを同じ投影に乗せる** — `PixelSprite#draw3d` が距離から拡大率を決める。

ドット絵は文字列の並びで定義し、横に続く同じ色をひとつの矩形へまとめて描く。
座標は必ず整数へ丸めてから3倍に拡大するので、拡大してもピクセルの角が崩れない。

## 構成

```
main.rb                     起動用
lib/suiminkaizen/
  config.rb                 バランス定数（調整はここだけで完結する）
  palette.rb  px.rb         色と、ドット単位の描画ラッパー
  pixel_sprite.rb  sprites.rb   文字列から作るドット絵
  camera.rb  stage.rb       疑似3Dの投影と部屋
  sleep_gauge.rb  game_state.rb  ゲームの状態
  hud.rb                    ゲージと「眠気」の画面効果
  scene.rb  window.rb       シーンの土台とウィンドウ
  scenes/                   タイトル／1日の導入／リザルト／睡眠／終幕
  minigames/                base.rb と3種目
spec/                       テスト（minitest）
tools/                      開発用ツール
```

## 開発用ツール

いずれも画面を開かずに動く（`tools/stub/gosu.rb` が Gosu を肩代わりする）。

```bash
ruby spec/all.rb            # テスト
ruby tools/smoke.rb         # 腕前の違う4人で通しプレイして例外・バランス・所要時間を確認
ruby tools/render.rb        # 各画面を PNG に書き出す（ソフトウェアラスタライザ）
ruby tools/sprite_sheet.rb  # ドット絵を並べて確認
ruby tools/real_shots.rb    # 本物の Gosu でオフスクリーン描画して PNG 保存
ruby tools/gosu_check.rb    # 実機でウィンドウを開いて数秒動かす起動確認
```

`tools/smoke.rb` の出力例:

```
達人 (0.95)      Ending    day=7 gauge=   0   32.8分
中級 (0.72)      Ending    day=7 gauge= 614   32.8分
初心者 (0.45)     GameOver  day=3 gauge=1000   12.3分
無操作            GameOver  day=2 gauge=1000    6.4分
```
