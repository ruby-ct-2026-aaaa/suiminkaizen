# 睡眠改善プロジェクト 〜ショートスリーパー峰小輔の一週間〜

ドット絵＋疑似3D（1点透視）のミニゲーム集。Ruby + [Gosu](https://www.libgosu.org/) 製。

ショートスリーパーの **峰小輔** が、1日4枠のイベントをこなして **睡眠ゲージ** の
上昇を食い止める。ゲージが 1000 に達したら気絶＝ゲームオーバー。1日を乗り切ると
夜に **30分だけ** 眠ることが許され、ゲージが 30 だけ減る。これを7日間くり返し、
一度も気絶させなければ勝ち。

選択画面とリザルト画面はどちらも **最大10秒**。即決すれば1日 70 秒・7日で **約8分**、
毎回10秒使いきると1日 150 秒・7日で **約17分半** になる。

## 動かす

### Windows（いちばん簡単）

**`start_game.bat` をダブルクリックする。**

Ruby が PATH に入っていなくても `C:\Ruby*` などから自動で探し、gosu が未導入なら
入れてから起動する。黒いウィンドウが一緒に開くが、閉じずにそのままにしておくこと。

> GitHub のページ上でファイルをクリックしても実行はされない。
> 一度 `git clone`（または Code → Download ZIP）して手元に持ってくる必要がある。

### コマンドから

```bash
gem install gosu
ruby main.rb
```

Ruby が PATH にない場合は実行ファイルを直に指定する。

```bat
C:\Ruby40-x64\bin\ruby.exe main.rb
```

必要なのは Ruby と gosu だけ。背景・小物・エフェクトはすべてソースコード中の
文字列から生成していて、外から持ってくるのは峰小輔の立ち絵4枚と音声6本だけ。

### 画面の大きさ

ウィンドウは端をドラッグして自由に伸縮でき、**F11**（または Alt+Enter）で全画面に
なる。絵の縦横比は 4:3 に保たれ、あまったぶんは黒帯になる。

### 他の人に遊んでもらうには（Ruby 同梱の配布パッケージ）

gosu は Windows 用のビルド済みパッケージが配布されておらず、導入時に必ず
コンパイルが走る。つまり素のリポジトリを渡すと、相手に **Devkit 付きの Ruby** を
入れてもらうところから始まってしまう。

そこで、Ruby ごと同梱した ZIP を作れるようにしてある。

```bash
ruby tools/build_windows_package.rb
powershell Compress-Archive -Path tmp/dist/suiminkaizen -DestinationPath tmp/dist/suiminkaizen_windows.zip -Force
```

できあがる ZIP は **18 MB 前後**（展開後 53 MB）。相手は解凍して
`start_game.bat` を押すだけで、**何もインストールせずに**遊べる。

`libgcc_s_seh-1.dll` と `libwinpthread-1.dll` は `gosu.so` が直接要求するため、
MSYS2 を外す以上は個別に同梱しないと **起動しない**。ビルドスクリプトは最後に
「MSYS2 が見えない状態で gosu を読み込めるか」まで確認するので、
同梱漏れがあればその場で失敗する。

## 操作

| キー | 働き |
| --- | --- |
| `SPACE` / `Enter` | 決定・筋トレのバーベル・サプリを飲む・ウトウトからの復帰 |
| `↑` `↓` | 難易度を選ぶ |
| `←` `→` | 選択画面で種目を選ぶ |
| `N` | 選択画面で「何もしない」を選ぶ |
| `←` `→` | 筋トレの軸のブレを戻す／サプリのコップを動かす／お風呂の湯量 |
| `↑` `↓` | 筋トレの呼吸（交互）／お風呂の湯温／サプリの水と払いのけ |
| `← ↑ → ↓` `SPACE` | ヘッドマッサージで表示された手順を順に押す |
| `9` | 乱入してきたクイヤを追い払う（連打） |
| `F11` | 全画面の切り替え（Alt+Enter でも可） |
| `ESC` | ポーズ（ポーズ中に `T` でタイトル、`Q` で終了） |
| `R` | ゲームオーバー／クリア画面からやり直し |

## ルール

### 難易度

はじめるときに5段階から選ぶ。変わるのは **眠気の進む速さ**ひとつだけで、
ミニゲームの内容も削減量も変わらない。この画面は時間で勝手に進まず、
選ぶまでいつまでも待つ。

| 難易度 | 倍率 | DAY1 の眠気 | 何もしなければ |
| --- | --- | --- | --- |
| 赤ちゃん | x0.45 | 4.5 / 秒 | 約 222 秒で気絶 |
| 初心者 | x0.80 | 8.0 / 秒 | 約 125 秒で気絶 |
| **普通** | x1.15 | 11.5 / 秒 | 約 87 秒で気絶 |
| 上級者 | x1.50 | 15.0 / 秒 | 約 67 秒で気絶 |
| プロ | x1.85 | 18.5 / 秒 | 約 54 秒で気絶 |

刻みの基準は「等倍（10/秒）が初心者と普通のちょうどあいだ」。

### クイヤ

睡眠ゲージが **500 を超える**と、「クイヤ」という動物がミニゲームに乱入してくる。
居座られているあいだ、眠気の進みが **1匹につき 5%** 速くなる。

クイヤは **9 が大の苦手**なので、`9`（テンキーでも可）を **9回** 叩きこめば
その場で飛び跳ね、**0.5秒でフェードアウト**して消える。手前にいる個体から順に効く。
居座っているあいだは **4秒おき**にひと声鳴く。

| 難易度 | 同時に出てくる数 |
| --- | --- |
| 赤ちゃん／初心者 | 出てこない |
| 普通 | 1 匹 |
| 上級者 | 2 匹 |
| プロ | 3 匹 |

ゲージが 500 を下回れば、居座る理由がなくなって勝手に帰っていく。
1日が終わればいったん解散する。

歩く6コマ・走る4コマ・待機・正面・後ろ姿・驚く・食べる・寝るの計16コマを
1枚のシートから切り出して使っている（`tools/prepare_kuiya.rb`）。

### 睡眠ゲージ


- **0 が通常** ＝ 健康。**1000 で気絶** ＝ ゲームオーバー。
- 時間が経つだけで溜まる。日が進むほど溜まる速度が上がる。
- ミニゲームでのミスは、その場でゲージを増やす。
- 1日を乗り切った夜、30分の睡眠で **30 だけ** 減る。7日間しのげばクリア。

### 1日の流れ

ゲームは **00:00** からはじまる。まず峰小輔が **30分だけ**眠り、**00:30** で1日が開幕する。

1日は 4 枠 ＝ ミニゲームを合計 4 回プレイできる。画面上部の
**24時間デジタル時計** が 00:30 から 00:00 へ進んでいき、就寝は
その **00:00 ちょうど**から。30 分だけ眠って 00:30 ＝ちょうど翌日の始まりに戻る。
ショートスリーパーの24時間がぴったり一周する。

- 3 枠は、枠の頭で **3つの選択肢（筋トレ／お風呂／サプリメント）** が並び、
  `←` `→` で選んで `SPACE` ではじめる。選んでいる種目のルールがその場に出る。
  画面が切り替わった **最初のフレームから `SPACE` が効く**ので、
  決まっているなら一瞬で飛ばせる。この画面は **時計も睡眠ゲージも止まる**ので、
  じっくり選んでも損はしない。
  `N` を押せば **何もしない**。ミスもしないが削減もゼロのまま時計だけが進むので、
  **ミニゲームを1つもやらずに1日を終えることもできる**。
- 迷っていられるのは **10秒**まで。超えると **ランダムに1つ選ばれて強制的に始まる**。
- 残り 1 枠は **ヘッドマッサージ師の乱入**。予定には載らず（？で伏せられる）、
  断ることも選ぶこともできない。

### リザルト画面

1枠ごとのリザルトは **最大10秒**。`SPACE` を押せばすぐ次へ、押さなくても10秒で
自動的に進む。この画面のあいだは **睡眠ゲージも24時間時計も止まる**ので、
落ち着いて成績を読める。

### ミニゲーム（1本 15秒）

どれも「1つのキーを待つ」だけでは終わらないよう、**同時に2〜3系統をさばく**形にしてある。

| 種目 | 内容 | 操作 |
| --- | --- | --- |
| **深夜の筋トレ** | 往復するパワーゲージを緑のゾーンで止める（中央の黄色なら PERFECT）。同時に、勝手にブレていく**軸**を中央へ戻し、**呼吸**を `↑` `↓` の交互押しで切らさない。軸がブレたまま上げる・息が切れる・よろける、どれも事故。 | `SPACE` `←` `→` `↑` `↓` |
| **お風呂** | **湯温**と**湯量**、2本のメーターをどちらも動く緑の帯に保つ。`↓`（うめる）や `→`（足し湯）は湯量まで動かすので、片方を直すともう片方がずれる。「ウトウト…」が出たら即 `SPACE`。 | `↑` `↓` `←` `→` `SPACE` |
| **サプリメント** | **寒色**（カフェイン・ミント・タウリン・エナジー）は `SPACE` で飲む。**暖色**（ホットミルク・カモミール・甘酒）は身体が温まって眠くなるので `↓` で払いのける。飲んだ直後は「水！」のうちに `↑` で流し込まないとむせる。 | `←` `→` `SPACE` `↓` `↑` |
| **ヘッドマッサージ** | 乱入イベント。気持ちよさが溜まりきるといびきをかいて大ダメージ。出てくる**手順**（例：`←` `SP` `↓`）を順番どおりに押しきる。レベルが上がるほど手数が伸びる。 | `← ↑ → ↓` `SPACE` |

### 削減量は「成功の難易度」で変わる

各ミニゲームは制限時間 15 秒でスコアを稼ぐ形に統一してある。

```
達成率 = スコア / 目標スコア   （上限 1.2）
削減量 = その日の上限 × 達成率
```

削減はミニゲームが終わってからではなく、**得点が入ったその瞬間**に反映される。
成功するたび、画面上部の睡眠ゲージと数値がその場で減っていく。

スコアは **レベル**（種目内の難易度。粘るほど速く・シビアになる）と **コンボ** で
1回あたりの価値が上がるので、難しい成功ほど多くゲージを削れる。1枠あたりの削減量の
上限も DAY1 の **306** から DAY7 の **444** まで増えていく。

眠気の溜まる速さは、等倍なら **1日目ちょうど 10/秒**。日が進むごとに上がっていき、
7日目には 15.11/秒 になる。ここに難易度の倍率がそのままかかる。

### バランスの考えかた

- ミスを出さずに丁寧にこなせば、等倍で達成率 **50% 前後**（普通なら 58% 前後）で
  収支が釣り合う。
- 選択画面で毎回10秒使いきると、要求される達成率がはっきり上がる。
- 何もしなければ **2 日ともたない**。

数値は [`lib/suiminkaizen/config.rb`](lib/suiminkaizen/config.rb) に集約してあり、
[`spec/core/balance_spec.rb`](spec/core/balance_spec.rb) がこの関係を見張っている。

## 想定プレイ時間

ミニゲーム本体は固定（4本 x 15秒 ＝ 1分ちょうど）で、残りはプレイヤーの決断しだい。

```
即決     : 60 + 朝4 + 夜3 + 睡眠3                    =  70秒/日  → 7日で約 8分
迷いきり : 60 + 4枠 x (選択10秒 + リザルト10秒) + 10 = 150秒/日  → 7日で約 17分半
```

選択画面もリザルト画面も、表示しているあいだは時計も眠気も止まる。
待っても損はしないので、実時間だけが延びる。

## 峰小輔の立ち絵


`assets/kosuke/` に 4 種類。場面によって使い分ける。

| ファイル | 使いどころ |
| --- | --- |
| `normal` | ふだんの峰小輔（タイトル・1日の導入・選択画面・**筋トレ**・**お風呂**・マッサージ中） |
| `success` | ミニゲームで **A 以上** を出したとき、そしてクリア画面 |
| `fail` | ミニゲームで **C 以下** だったとき、そして気絶画面 |
| `sleep` | 1日の終わりの30分睡眠、マッサージで寝落ちした瞬間 |

元は白背景の JPG なので、外周から白につながった領域だけを塗りつぶしで探して
透明にしている（`tools/prepare_sprites.rb`）。単純に白い画素を消すと目の白や
肌のハイライトまで穴が空くため、外周から到達できるかどうかで判断している。

## 疑似3Dのしくみ

`x:右 / y:下 / z:奥` の世界座標をカメラ原点から `screen = 中心 + 座標 / z × 焦点距離`
で投影しているだけの、ごく単純な1点透視。立体に見せているのは次の3点。

1. **床・天井・壁を透視で敷く** — 奥行き方向のグリッドが消失点へ収束する。
2. **頂点カラーでフォグをかける** — 奥ほど背景色へ沈み、空気遠近になる。
3. **スプライトを同じ投影に乗せる** — 距離から拡大率が決まる
   （`PixelSprite#draw3d` と `ImageSprite#draw3d`）。

ドット絵は文字列の並びで定義し、横に続く同じ色をひとつの矩形へまとめて描く。
座標はまず論理ドットの整数へ丸め、そのうえで `Viewport` の倍率をかけてから画面座標の
整数へ落とす。両端を同じ手順で丸めるので、ウィンドウをどんな大きさにしても
隣り合う矩形のあいだに隙間ができない。

## 開発用ツール

画面を開かずに動くもの（`tools/stub/gosu.rb` が Gosu を肩代わりする）と、
本物の Gosu を使うものがある。

```bash
ruby spec/all.rb            # テスト
ruby tools/smoke.rb         # 腕前の違う4人で通しプレイして例外・バランス・所要時間を確認
ruby tools/render.rb        # 各画面を PNG に書き出す（ソフトウェアラスタライザ）
ruby tools/sprite_sheet.rb  # ドット絵を並べて確認
ruby tools/prepare_sprites.rb        # 立ち絵の白背景を抜いて PNG 化
ruby tools/prepare_kuiya.rb          # クイヤのシートを16コマに切り出す
ruby tools/real_shots.rb             # 本物の Gosu でオフスクリーン描画して PNG 保存
ruby tools/gosu_check.rb             # 実機でウィンドウを開いて数秒動かす起動確認
ruby tools/build_windows_package.rb  # Ruby 同梱の配布パッケージを組み立てる
```

`tools/smoke.rb` の出力例:

