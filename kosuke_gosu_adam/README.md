# 峰小輔の7日間 — LIVE edition v0.2.1

Ruby + Gosuで、ドット絵の疑似3Dの部屋を歩き、5種類のミニゲームで睡眠・気絶ゲージを下げるゲームです。
0から開始し、1000で強制睡眠＝ゲームオーバー。7日間乗り切れば勝利です。

視聴者視点では、動作に反応するコメントが右から左へ流れます。
ミニゲーム中も右側にチャットを表示し、プレイしながら視聴者の反応を読めます。
ミニゲームには、提供された人物画像をもとにした4コマのドット絵アニメーションを追加しました。
レトロなPCウィンドウとピンク・ラベンダーの配信画面で、可愛さと眠気の不穏さを表現しています。

## 今回の追加

- ニコニコ風の流れるコメントと、架空の視聴者チャット。成功・ミス・眠気・日付・勝敗に反応します。
- 「整体・まぶた防衛」「配信カメラ救出」を追加し、全5種類に。
- ダンベルで頬を膨らます、アヒルが跳ねる、イスに負けかけるなど、競技ごとのアニメーション。
- 睡眠ゲージの自然増加を前版の1.5倍に変更。
- 550 / 750 / 900でクイヤの幻覚が1 / 2 / 3体出現。9キーで一時的に追い払えます。
- C＝流れるコメントの表示切替、V＝視聴者／プレイヤー視点、H＝演出を弱める。

既存の3種、3段階の難易度、成功度による回復、仮眠、7日間の勝敗、移動・当たり判定・一時停止は維持しています。
配信とコメントはゲーム内の演出です。実際の配信サイトへの接続やコメント投稿は行いません。

## 起動

Rubyが入っているPCでZIPを解凍し、`main.rb` のあるフォルダで次を実行します。

```sh
gem install gosu -v 1.4.6
ruby main.rb
```

Windowsでは、インストール後に `start_windows.bat` をダブルクリックしても起動できます。
Rubyがない場合は [RubyInstaller](https://rubyinstaller.org/downloads/) のRuby+Devkitを使用してください。
Gosuの導入については [公式案内](https://www.libgosu.org/ruby.html) を参照してください。
macOS/Linuxは同ページから各OSの依存ライブラリの案内を開けます。

Ruby 3.1以上を想定。動作確認はRuby 3.3.10 / Gosu 1.4.6 / Linuxで実施しています。
日本語フォントを同梱しています。配布物をフォルダごと保ったまま実行してください。

## 操作

| 場面 | 操作 |
|---|---|
| タイトル | Enter / スタートボタン |
| 部屋の移動 | 矢印・WASD・床をクリック |
| 設備へ移動 | 1＝筋トレ、2＝お風呂、3＝サプリメント、4＝整体、5＝カメラ救出。設備前まで自動で歩く |
| 近くの設備を使う | E |
| 難易度 | 1〜3、クリック、または左右→Enter |
| 筋トレ | 中央を狙ってSpace / LIFTボタンを5回 |
| お風呂 | 左右 / A・D / 左右ボタンの長押し |
| サプリメント | 覚えた順に1〜4 / ボタン |
| 整体 | 矢印が出たら左右 / A・D / ボタンで同じ方向を押す |
| カメラ救出 | 光ったカメラの番号1〜6 / クリック |
| 視聴者演出 | C＝流れるコメント、V＝視点、H＝演出の強さ |
| クイヤを追い払う | 9。4.5秒間姿を消し、6秒後に再使用可。ゲージは減らない |
| 結果を閉じる | Enter |
| 1日クリア | Enter＝30分仮眠、N＝仮眠をスキップ |
| 一時停止・再開 | Esc。ウィンドウが操作対象から外れたときも自動で停止 |
| 最初から・終了 | 一時停止画面でR / Q |

## ルール

- ゲージは翌日に持ち越します。1000に一度でも到達すると敗北です。
- 1日の起きている時間は実時間90秒。説明・結果・一時停止中は時間が止まります。
- ミニゲーム中もゲージが増えます。成功すると難易度と成功度に応じて減ります。
- 1日の自然増加は1日目+975から7日目+1425。失敗が続くと次の日に持ち越した眠気が危険になります。
- 1日を終えると、30分の仮眠で30減らせます。ゲージの下限は0です。
- 同じ設備はプレイ後12秒間使用できません。他の設備は使えます。
- 残り8秒以下では新しいミニゲームを始められません。日が終わるまで部屋で待ってください。
- 7日目の終了画面から進むと勝利画面になります。

難易度の目安は、やさしい＝−80〜120、ふつう＝−140〜200、むずかしい＝−210〜300。
ゲージが小さいと余った回復分は切り捨てられます。失敗時の回復は0です。

数値は試作用です。詳しい設計・計算式・追加方法は [DESIGN.md](DESIGN.md) を参照してください。
架空キャラクターのゲームであり、睡眠・健康・サプリメントの効果はゲーム内の設定です。

## 開発

最初に読むファイル：`config/balance.rb` → `lib/game_state.rb` → `lib/stream_window.rb`。
従来の入力・進行処理は `lib/game_window.rb`、配信演出はその派生クラスに分けています。

```sh
# Gosuなしで進行・採点・経路探索をテスト
ruby test/test_game.rb

# Gosuを使った入力・描画の確認
ruby test/smoke_gosu.rb

# 描画されたボタンの座標で全5種のクリック・長押しを確認
ruby test/smoke_mouse.rb

# 移動と全5種の採点を通した7日間の自動プレイ
ruby tools/simulate_week.rb

# 各画面のスクリーンショット
ruby tools/capture.rb

# アニメーション確認用の連番PNG
ruby tools/capture_animation.rb
```

部屋の歩行キャラは従来の仮ドットを維持し、ミニゲーム用の描き起こし素材は `assets/action_sprites.png` に収録。
原画像はプレイヤー視点の人物欄に表示します。クイヤの絵は本ゲーム用の独自解釈です。
途中保存は未実装です。終了や「最初から」を選ぶと1日目に戻ります。
フォントのライセンスと出典は [CREDITS.md](CREDITS.md) に記載しています。

実行確認：27項目・1780 assertionsの自動テスト、22項目のGosu入力確認、通常描画30フレーム。
移動・出題・採点を含む自動プレイヤーでも7日間勝利しました。人間による難易度調整は今後のプレイテストで行えます。
Windows/macOSの実機確認は未実施です。
